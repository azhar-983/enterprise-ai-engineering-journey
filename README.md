# enterprise-ai-engineering-journey

Hands-on journey into enterprise AI engineering, forward deployed engineering, and agentic AI. Build production-oriented AI applications using Python, FastAPI, LLMs, RAG, LangGraph, and Kafka.

## Python environment

The exercises currently have no third-party package dependencies. From the repository root, create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

On Windows PowerShell, activate it with:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
```

When the environment is active, `python` and `pip` use the environment. Deactivate it with `deactivate`. The `.venv` directory is local to your machine and is ignored by Git.
